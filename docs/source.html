Clone with Fossil

Install Fossil, clone the repository database, then open it into a working directory.

Clone and openshell
fossil clone https://code.cloudz.cv/oodz_agent/ oodz_agent.fossil
mkdir oodz_agent
cd oodz_agent
fossil open ../oodz_agent.fossil

The .fossil file contains the repository history. The oodz_agent directory is your editable checkout.

Verify a checkout

Offline testsshell
tclsh9.0 tests/all.tcl

The test suite exercises the agent loop, providers, plugins, process execution, persistence, GUI helpers, and safety limits without requiring a live model API key.

Development workflow

Common Fossil commandsshell
fossil status
fossil diff
fossil update
fossil timeline -n 20

Read the repository documentation and run the complete test suite before committing changes. If Fossil is new to you, its official quick start guide explains checkouts, updates, and commits.
