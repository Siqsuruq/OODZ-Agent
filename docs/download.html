Requirements

  • Tcl 9.0 or newer and Tcl Thread 3.0 or newer
  • Tcl TLS and Tcllib packages http, json, json::write, and fileutil
  • Tk to use the graphical interface
  • A supported model provider, such as DeepSeek or a local Ollama server

See Getting started for platform notes and a package check.

Install and verify

Extract the archive, enter its directory, create your private configuration, and run the offline tests before adding an API key.

Linux / FreeBSDshell
unzip oodz_agent-trunk.zip
cd oodz_agent-trunk
cp conf/conf.example.ini conf/conf.ini
chmod 600 conf/conf.ini
tclsh9.0 tests/all.tcl
tclsh9.0 main.tcl
Windows PowerShellpowershell
Expand-Archive .\oodz_agent-trunk.zip
Set-Location .\oodz_agent-trunk
Copy-Item conf\conf.example.ini conf\conf.ini
tclsh9.0.exe tests\all.tcl
tclsh9.0.exe main.tcl

Edit conf/conf.ini before connecting to a provider. Command execution and the Tcl runner are disabled by default; enable them only after reviewing their permission settings.
