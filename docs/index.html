Why OODZ

An agent you can understand, extend, and control.

OODZ is built for professionals who know their tools and want the model to operate through explicit capabilities instead of an opaque, unrestricted shell.

Small and inspectable

The Tcl codebase and plugin contract are compact enough to read, audit, debug, and adapt to a real working environment.

Tiny programmable tools

Add a focused plugin with a manifest and a Tcl handler. Plugins can use Tcl packages, external programs, Expect, or private domain logic.

Your choice of model

Use a hosted DeepSeek-compatible endpoint or local Ollama models. OODZ keeps the tools, history, and workflow independent of one model vendor.

Explicit professional controls

Tool schemas, workspace confinement, write approval, allowlisted commands, timeouts, and output bounds make actions visible and configurable.

Public core, private expertise

Combine bundled plugins and skills with private ones for internal services, frameworks, project conventions, and organization-specific workflows.

Context that survives restarts

Conversation history is stored locally, bounded for the model, and compacted into summaries so long-running work can continue across sessions.

Capabilities

Useful now, designed to grow.

Agent loop

The configured model can choose tools, inspect results, and continue until it produces a final answer.

Controlled plugins

Workspace confinement, schemas, timeouts, output limits, and explicit write approval.

Persistent REPL

Conversation context survives restarts and can be reset at any time with /new.

Clean terminal

Streaming answers stay in the conversation while diagnostics go to a separate log.
