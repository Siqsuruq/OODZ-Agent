Getting started

Install the runtime, configure DeepSeek or Ollama, and learn the interactive commands.

RequirementsConfigurationRun the agentCLI commands

Requirements

  • Tcl 9.0 or newer
  • Tcl TLS package
  • Tcllib packages: http, json, json::write, and fileutil

The repository bundles inifile, tConfClass, tLogger, and zesty.

Check packagesshell
tclsh <<'EOF'
foreach package {Tcl tls http json json::write fileutil} {
    puts "$package [package require $package]"
}
EOF

Configuration

Create the ignored private configuration, restrict it to your user, and then edit it:

Create private configurationshell
cp conf/conf.example.ini conf/conf.ini
chmod 600 conf/conf.ini

Git and Fossil ignore conf/conf.ini. Publish only conf/conf.example.ini, which contains placeholders and conservative defaults.

Workspace.instructions names an optional UTF-8 instruction filename. The root file is sent with every request. Before changing nested files, load_project_instructions discovers matching files from the workspace root through the target directory. Closer instructions refine conventions for their subtree. Leave the setting empty to disable project instructions.

Plugins.directories accepts comma-separated absolute or installation-relative personal plugin roots. Each configured directory must already exist.

Skills.directories accepts comma-separated personal skill roots. Skill names and trigger descriptions are included in the system prompt; complete instructions are retrieved only when the model calls load_skill.

Executables.fossil configures one trusted executable name or absolute path for every bundled Fossil plugin. The default fossil resolves through PATH. On Windows, a full path may be written as C:/Tools/Fossil/fossil.exe.

Windows

Use forward slashes for absolute INI paths, for example D:/projects/client. The built-in skills/ directory is always loaded; personal skill roots may be anywhere and are added with Skills.directories. The CLI selects the UTF-8 console code page and uses ASCII borders for CMD and PowerShell compatibility.

PowerShellpowershell
Copy-Item conf\conf.example.ini conf\conf.ini
tclsh90.exe .\main.tcl
wish90.exe .\gui.tcl

GUI.theme_package optionally loads a Tcl package from lib/ or one of its immediate package directories. GUI.theme then selects one of the themes provided by that package. Leave both empty to use the platform default. The example loads the bundled Arc package and selects Arc-Dark; use Arc for its light variant. Invalid package or theme names stop GUI startup with a clear error.

When both Arc variants are available, the action bar includes a Dark toggle for switching the current GUI session. The configured GUI.theme remains the preference used at the next startup.

Danger: this is not a safe agent. The default direct runner executes AI-created Tcl with the same operating-system permissions as the user. It can read, modify, or delete accessible files, start processes, access the network, and inspect environment variables. Enable it only if you understand the consequences and maintain recoverable backups or version control.

run_tcl_file accepts only an approved workspace-relative Tcl file and enforces time/output limits, but the direct backend provides no OS isolation. Every execution receives a separate approval; “All for session” does not apply. Linux users may select Runner.backend = bubblewrap for optional containment. Set Runner.enabled = false to remove execution entirely.

Enable Runner.project_tests_enabled to expose run_project_tests. Its executable and Tcl-list arguments come only from trusted configuration; the model supplies no command fields. The profile uses the same backend and always requires separate approval.

Keep the key private. Do not commit or share a real API credential.

Local Ollama

Ollama uses the same OpenAI-compatible client. Choose a locally installed model that supports tool calling.

[LLM]

api_key =

thinking = false
timeout = 60000
max_retries = 2
retry_delay_ms = 250

Run the agent

Interactiveshell
tclsh main.tcl

Interactive responses stream to the terminal and conversation context persists across restarts.

One shotshell
tclsh main.tcl "Explain the plugin architecture."

One-shot mode remains stateless and prints one complete answer to standard output.
