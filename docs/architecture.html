Agent loop

  1. Combine stored history with the new user task.
  2. Send messages and plugin schemas to the configured provider.
  3. Append the assistant message.
  4. Execute requested plugins and append their results.
  5. Repeat until final content arrives or the iteration limit is reached.
  6. Commit and persist history only after success.

API behavior

Interactive

SSE fragments stream to the terminal. An unexpectedly empty stream falls back to one buffered request.

One shot

The client buffers the complete response so scripts receive clean standard output.

Retries

Transport failures, HTTP 429, and HTTP 5xx responses use bounded exponential backoff.

Messages

Canonical dictionaries preserve content, reasoning metadata, tool calls, and tool results.
